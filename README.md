Installation Steps:

Open about:config in the Firefox address bar.

Search for toolkit.legacyUserProfileCustomizations.stylesheets.

Toggle its value to true.

Open Firefox and go to about:support.

Find the Profile Folder entry and click Open Folder.

Inside the profile folder, open (or create) a folder named chrome.

Copy userChrome.css and all related image assets (asukabanner1.png, asukapxl4-red.png, etc.) directly into that chrome folder.

Restart Firefox completely (Ctrl+Shift+Q)
